# AGNESai Image Host

Public image hosting for AGNESai reference images (video/image generation).

## URL 格式

上传到 `images/` 目录后，图片可通过以下两种方式访问：

- GitHub raw: https://raw.githubusercontent.com/gxtgxtgxtgxt/agnes-img-host/main/images/<文件名>
- jsDelivr CDN: https://cdn.jsdelivr.net/gh/gxtgxtgxtgxt/agnes-img-host@main/images/<文件名>

## 上传工具

使用仓库外的脚本：`D:/Users/Administrator/codex-folder/agnes_img_upload.py`

## 注意

- 本仓库必须保持 public，AGNES 服务器才能无需认证访问图片
- 图片在任务完成前需保持可访问，请勿删除正在使用的图片
